## Global constraints

- Pinned model and runtime; seeds `20260916` / `20260924`. Nothing outside the 255 exposed tokens, 90 exposed frames and 80 nouns is executed before `confirm`; the lock phase runs no forward pass (`_weights_only`, no capture API reachable); no fresh cue prompt before its frame's stage-1 lists and table are digested and re-read from disk.
- **Boundary:** every prospective rung receives `ΔE`, the weights, the locked axes, read and bases, the locked score tables and lists, and the frame's reference run only; every selector list is an explicit index list; the oracles are built at stage 2 from stage-2 measurements, applied to the same predicted upstream parts, and written into no selector, table or list.
- **Objects:** per rung and pair `ĉ_L = r(Δ̂x₃(p_c) − ΔE) / D_T`, `F̂`, `Π̂`, `ΔT̂`, the row (Experiments 017–018, verbatim); `u_j = e_j · r(W_out^{(2)}[j, :]) / D_T` at `p_c`; `κ_X(S)` unclipped, `None` below a `0.05` gap; `Δκ_k(X) = κ_{c_L}(X_k) − κ_{c_L}(S'_k)`; `ρ_k = Δκ_k(G) / Δκ_k(E)` per set and pooled, unclipped; `H*_k = κ_{c_L}(O*_k) − κ_{c_L}(S'_k)`, `H_k` likewise for `O_k`.
- **Floors and rules (named constants, tested against the spec):** decision size `64`; Y1/Y2 `Δκ_64(E) ≥ 0.05` pooled, `E_64(f)` above `S'_64` in per-frame `c_L R²` in strictly more than half of the valid frames (a tie is not a win), `Δκ_64(E) ≥ 0.02` on the cue-final and on the coordinated split; negative → `NOT_PREDICTED` iff `H*_64 ≥ 0.05` or `Δκ_64(E) ≥ 0.05`, else `NOT_EVALUABLE`; Y3 evaluable iff `Δκ_64(E) ≥ 0.05` on Y1, on Y2 and pooled, then `ρ_64 ≥ 0.60` pooled and `≥ 0.50` on each set; Y4 `A = κ(E_64) − κ(T_64)`, `B = Δκ_64(T)` on Y2 and pooled with `0.05` margins, three-way plus the set-dependent case; Y5 per set: mean `|E_64 ∩ O_64| / 64 ≥ 0.60` and `≥` the same for `S'_64` `+ 0.20`; preconditions: reference rung `c_L ≥ 0.98`, rows `≥ 0.95`, `ΔT ≥ 0.95`, `c_L` gap `≥ 0.05` pooled and on each family split, 16 scored tokens, tokens scored with `≥ 3` valid frames, Y2 `≥ 9` valid cue-final and `≥ 4` valid coordinated frames; drive quantiles `(0.1, 0.5, 0.9)` per template and position type; random controls `random.Random(20260924)`, `sample(range(2048), k)` three times for `k` in `(16, 64, 256)` in that order, one generator; identities I4–I7 as Experiment 017, I8 `1e-9` against the 018 record, I9 exact list equality, I10 `1e-9`; extract replication `1e-6`; locked-state check `1e-9` against the 018 lock and its stage-1 digests.
- **Terminology (report and README):** `O*` is a cross-validated empirical headroom witness; a high `H*_64` establishes transferable selectable headroom under the frozen witness; a low `H*_64` means the witness did not establish enough headroom for the fixed-population-versus-unpredicted distinction and is never rendered as proof that no frame-specific headroom exists.

Two structural rules make the table hold without relying on discipline: (1) the selectors' lists are computed in one function that receives locked states, weights and the exposed token ids only, and are never recomputed after they are digested — stage 2 reads them from the lock and the stage-1 record; (2) the witness is computed in one function `greedy_witness(train_u, train_y, k)` that receives the frame's *other* scored pairs' contribution vectors `u_j` and their measured `c_L` and nothing else — the held-out pair's own `u_j` enters only afterwards, when the returned mask is applied to it (`apply(mask, u_w)`) — and its output is stored per pair as an index list; a test changes the held-out pair's `u_j` *and* its measured `c_L` and checks that its mask is unchanged.

## Objects and naming

- Rungs (strings; every rung has every object column): `S0`, `S2048` (reference); `Sp1` (`S'_1`), `Sp16`, `Sp64`, `Sp256`; `T16`, `T64`, `T256` (resolved per pair's template and position); `E1`, `E16`, `E64`, `E256` and `G16`, `G64`, `G256` (per frame and position); `L16`, `L64`, `L256` (the inherited 018 `S_k`, both positions); `R1_16 … R3_256`; stage-2 only: `O16`, `O64`, `O256` (per frame and position) and `Os16`, `Os64`, `Os256` (per pair at `p_c`; `O_k(f, p_t)` at `p_t`). Prediction-table columns `{obj}_{rung}` for `obj ∈ {c_L, F, Pi, dT}` and `row_{rung}`, plus `dT_frozen`, `c_L_level0F`; the stage-2-only rungs have no table column and live in the stage-2 record.
- Lists in the lock: `selectors.Sprime[position_type][k]`, `selectors.T[template][position_type][k]`, `selectors.E[frame_id][position][k]`, `selectors.G[frame_id][position][k]`, `selectors.Sp1`, `selectors.E1[frame_id][position]`, `selectors.L[k]` (digest-checked against the 018 lock), `selectors.R[k][i]`, `drive_quantiles[template][position_type][q]` (2048 floats each), `scores` (the `S'`, `T`, `E`, `G` score vectors, so that `validate_lock` reproduces the lists). Stage 1 stores the same structure for the 18 frames plus `overlaps[frame_id][position]` among `Sprime`, `T`, `E`, `G`.
- Stage-2 record per pair: the measured objects, `e_meas_fidelity` (`R²` of `e_j` against `e_j^meas`), the witness lists `Os[k]` (sorted indices), and every rung's predictions including the oracle rungs; per frame `O[k][position]`.
- Scoring output: per set `precondition`, `Y` (with `delta_kappa`, `wins`, `split_gains`, `headroom_star`, `headroom_proxy`, `label`), Y3 (`rho` per set and pooled, `evaluable`, `label`), Y4 (`A`, `B` per set and pooled, `label`), Y5 (per set), descriptives (i)–(x) of the spec, per frame, token means, the ladder at every `k`; `outcome = Y1 | Y2 | Y3 | Y4 | Y5`.
