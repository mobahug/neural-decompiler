# Synthesis

This directory holds the synthesis of the regular-plural experimental sequence, Experiments 005–025. Experiment 025's
preregistered stopping rule ended that sequence; the synthesis looks back across it before any new sequence is
considered.

The synthesis proceeds in three steps, each reviewed before the next:

1. **The source map** — a factual inventory of what each experiment asked, froze, ran and found, built from the
   committed experiment READMEs and evidence. It interprets nothing.
2. **The synthesis** — what the sequence established about the original question, and whether a genuine unresolved
   mechanistic gap remains. It is built only on the reviewed source map.
3. **The decision** — a write-up, or a new research sequence with a fresh preregistration. A new sequence needs a
   clear, new, falsifiable question; a descriptive finding of an earlier experiment is not one by itself.

The experiment READMEs, their evidence directories and the claim files remain authoritative. These documents only
point to them; where a summary here disagrees with its source, the source wins.
